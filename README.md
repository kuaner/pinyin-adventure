# 拼音闯关大冒险 🐣

给学拼音的小朋友（幼小衔接/一年级）的闯关练习应用。针对"记不牢、左右镜像写反、易混淆"三个痛点设计。

## 玩法
- **闯关冒险**：按课本顺序 8 关（单韵母→声母→复韵母→前后鼻音→整体认读），每关 10 题混编（听音选字/看字选音/听看一致/口诀判断）
- **易混对专练**：b↔d、p↔q 镜像组，n↔l、f↔h 近音组，an↔ang、ui↔iu 韵母组，配课本口诀
- **正反小侦探**：字母正写/镜像翻转辨别训练（针对普遍性反写）
- **闪卡复习**：Leitner 三盒间隔复习（会啦 3 天后见 / 快会了明天见 / 还不会今天再见）
- **全部界面文字带拼音注音**（学拼音的孩子不识字也能自己玩）

## 智能
- **自适应出题**：答错的混淆对权重翻倍——越混什么越练什么
- 历史成绩页：家长可见"最容易混""最容易写反"排行

## 技术
单文件 HTML、零依赖、零外链、全 localStorage 本地保存。语音为预生成音频（mimo-v2.5-tts）+ 设备 TTS 双通道。

由 [Duoduo](https://openduo.ai) 与 kuaner 共同维护。
